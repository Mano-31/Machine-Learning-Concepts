# Machine Learning Concepts

## 📌 About This Repository

This repository contains fundamental Machine Learning concepts implemented using Python.

The main objective is to understand basic statistical concepts, data distribution, and data visualization through practical examples using NumPy and Matplotlib.

## 📚 Topics Covered

### 1. Standard Deviation
- Understanding Standard Deviation.
- Calculating Standard Deviation using NumPy.

### 2. Variance
- Understanding Variance.
- Calculating Variance using NumPy.

### 3. Percentile
- Understanding Percentiles.
- Calculating different percentile values.

### 4. Data Distribution
- Understanding Data Distribution.
- Generating random data using NumPy.

### 5. Normal Data Distribution
- Understanding data distribution visualization.
- Creating Histogram plots using Matplotlib.

### 6. Scatter Plot
- Understanding Scatter Plots.
- Visualizing relationships between two variables.
- Creating Scatter Plots using Matplotlib.

## 🛠️ Technologies Used

- Python

- Understand basic statistical concepts.
